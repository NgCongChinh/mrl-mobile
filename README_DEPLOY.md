## Cách xuất bản để dùng độc lập mọi nơi khi tắt máy tính
1. **GitHub Pages:** Đẩy toàn bộ nội dung thư mục `mobile_dist/` lên branch `gh-pages` hoặc thư mục `/docs` của repo GitHub.
2. **Cloudflare Pages / Vercel / Netlify:** Kéo thả trực tiếp thư mục `mobile_dist/` vào dashboard để nhận link HTTPS.
3. Mở link HTTPS trên Safari (iPhone) / Chrome (Android) → **Thêm vào màn hình chính (Add to Home Screen)**.
4. Trong tab **☁️ Đồng bộ**, nhập GitHub Personal Access Token (quyền `gist`) và `Gist ID` để đồng bộ 2 chiều tự động với bản `.exe` trên máy tính.
